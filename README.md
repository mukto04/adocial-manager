# Adocial — Performance Advertising Agency

Strategic, performance-focused advertising engineered to scale ambitious businesses worldwide.

## Built With
- **Framework:** [Next.js](https://nextjs.org/) (App Router)
- **Styling:** CSS & SASS (Fluid typography, custom responsive architecture)
- **Icons & Animations:** Vanilla CSS 3D keyframe animations & SVG icons

## Getting Started

First, install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Production Build

To build the project for production:

```bash
npm run build
npm run start
```
